# docs/work

경미하지 않은 새 개발 작업마다 **그 작업만의 작은 설계**(전체 설계가 아님)를 만들고 정리하는 공간이다. 경미한 변경(루트 CLAUDE.md 6절 기준)에는 쓰지 않는다.

## 이름 규칙

- 경로: `docs/work/{브랜치 이름}/MMDD_{문서-이름}.md`
- 브랜치 이름의 슬래시는 하위 폴더가 된다. 예: 브랜치 `feat/diary-feed` → `docs/work/feat/diary-feed/1106_diary-feed.md`
- 브랜치 폴더가 식별자 역할을 하므로 파일 이름에는 따로 식별자를 넣지 않는다.

## 규칙

- 경미하지 않은 새 브랜치에서는 **코드를 쓰기 전에 이 문서부터 만들어 첫 커밋**으로 푸시한다.
- 관련 PR은 Draft PR을 열기 전에는 「미정」으로 두고, 열린 뒤 PR 설명서를 커밋할 때 번호로 채운다.
- 작업하면서 진행 기록과 상태를 갱신한다.
- 병합 뒤 상태를 「완료」로 바꾸는 일은 **다음 작업 브랜치에서** 한다.
- 상위 설계와 다르게 구현해야 하면 먼저 `docs/design`에 변경 설계서를 쓰고 팀 합의를 받는다. 그 변경 설계서는 해당 항목에 한해 기존 설계보다 우선한다.
- 진행 중 가정한 내용(이름, 서식, 파일 위치 등)은 진행 기록에 한 줄로 남긴다.
